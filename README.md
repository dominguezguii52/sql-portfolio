# SQL Data Analysis Portfolio 📊

Welcome to my SQL portfolio! This repository contains progressive SQL scripts demonstrating data manipulation, multi-table relationships, and advanced analytics.

## Projects Included

1. **Sales Analysis (`sales_analysis.sql`)**
   - **Concepts:** Table creation, data insertion (`INSERT`), filtering (`WHERE`), and basic aggregation (`GROUP BY`, `SUM`).
   - **Scenario:** Local clothing business sales tracking.

2. **E-Commerce Performance Analysis (`ecommerce_analysis.sql`)**
   - **Concepts:** Foreign keys, `INNER JOIN`, sorting (`ORDER BY`), and multi-table metrics.
   - **Scenario:** Customer purchase behavior and spending metrics.

3. **Streaming Platform Analytics (`streaming_analytics.sql`)**
   - **Concepts:** Multiple joins, subqueries, and conditional logic (`CASE WHEN`).
   - **Scenario:** User engagement and content duration metrics for a streaming service.

## Technologies Used
- SQLite (DB Fiddle)
- Standard SQL (ANSI SQL compliant)
